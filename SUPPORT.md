# Support

| Need | Where |
| --- | --- |
| Bug | open an issue with the *Bug report* template |
| Idea or feature | open an issue with the *Feature request* template |
| New requirement | open an issue with the *Requirement* template |
| Security problem | private report, see [SECURITY.md](SECURITY.md) |
| Question | GitHub Discussions (once enabled) |

**This is not an emergency service.** In a real emergency in Germany call **112**; in the US call **911**.
