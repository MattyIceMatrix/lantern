# The Training Stack

```text
   LAYER 7  | PUBLISH      |  IEEE SSRR paper draft, talk, open release            | Op 7
   LAYER 6  | FIELD        |  dry field exercise, safety checklist, e-stop          | Op 5
   LAYER 5  | CREDENTIALS  |  EU A1/A3 drone cert, NVIDIA DLI certificate           | Op 2, 5
   LAYER 4  | DOCTRINE     |  FEMA IS-100/200/700/800/230, NFPA 1006, INSARAG, THW  | Op 0-5
   LAYER 3  | ENGINEERING  |  requirements, FMEA, test plan, DPIA, threat model     | Op 0-6
   LAYER 2  | BUILD        |  this repo: ROS 2, CV, LLM, agents, sync               | Op 1-6
   LAYER 1  | FOUNDATION   |  Udacity projects in the cluster map, done solo        | always
   =========+==============+========================================================+=======
```

Each layer makes the one above it believable. A paper (layer 7) without field tests (layer 6) is weak;
field tests without doctrine (layer 4) look naive to rescue professionals.

## Layer 1: Foundation (Udacity)

Do the matching Udacity project yourself **before** the LANTERN step that uses the same skill.
Udacity work is graded and must be your own (Honor Code). LANTERN is where you carry the skill further.

## Layer 4: Doctrine courses (all free, online)

```text
  [ ] IS-100.c  Introduction to the Incident Command System        Op 0
  [ ] IS-700.b  An Introduction to NIMS                            Op 0
  [ ] IS-200.c  ICS for Single Resources and Initial Action        Op 3
  [ ] IS-800.d  National Response Framework                        Op 4
  [ ] IS-230.d  Fundamentals of Emergency Management               Op 5
```

FEMA independent-study courses need a free FEMA Student Identification number (SID).
German context: read the BBK and THW public material on flood response and the THW unit structure.

## Layer 5: Credentials

| EU drone A1/A3 (open category) | Luftfahrt-Bundesamt (LBA) | about €25 | online exam, valid 5 years |

## Layer 6: Field

Real-world water rescue skills (NFPA 1006 Operations or Technician level) need in-person training with a
rescue organisation. LANTERN does **not** teach you to enter water. If you want those skills, look at a
local DLRG or THW chapter.

## Layer 7: Publish

Target: the IEEE International Symposium on Safety, Security, and Rescue Robotics (SSRR).
A workshop paper or poster with honest field numbers is a realistic goal.
